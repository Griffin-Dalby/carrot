CarrotCore

Core module & entry-point for the carrot framework. It aggregates all of the methods needed to read & parse semver strings.

Types​

Version​

</>
type Version = {
major: number,
minor: number,
patch: number
}

Primitive datatype that represents a deconstructed version, split up into their respective components.

ConvertibleVersion​

</>
type ConvertibleVersion = Version | string

Abstracted datatype allowing you to either pass a deconstructed Version, or a semver string that will then be deconstructed.

Functions​

parse​

</>
CarrotCore.parse(version: Version) → Version

Parses a version string, and deconstructs it into a format usable with the framework.

satisfies​

</>
CarrotCore.satisfies(
version: ConvertibleVersion,
requirement: string
) → boolean

Checks if a specific version fits a semver range requirement

format​

</>
CarrotCore.format(version: Version) → string

Reconstructs a Version table back into a semver string
