CarrotCore

Core module & entry-point for the carrot framework. It aggregates all of the methods needed to read & parse semver strings.

Types​

ReleaseType​

</>
type ReleaseType = "major" | "minor" | "patch

Defines the specific release types defined within the version string.

Comparator​

</>
type Comparator = ">" | ">=" | "<" | "<=" | "==" | "!="

Defines any comparator that can be used in a free comparison function, such as cmp(v1, Compartor, v2), and it will call the correlating comparison.

"===" and "!==" do simple string comparison, but are included for completeness.

compare​

Comparison
</>
CarrotCore.compare(
v1: ConvertibleVersion,
v2: ConvertibleVersion
) → number

View this on npm semver docs

Return 0 if v1 == v2, 1 if v1 is greater, or -1 if v2 is greater. Unlike a JavaScript Array.sort comparator, this numeric result cannot be passed directly to Luau table.sort(), whose comparator must return a boolean. Use lt as the sort comparator for ascending semantic-version order (for example, table.sort(versions, lt)).

coerce​

Coercion
</>
CarrotCore.coerce(version: string) → string

View this on npm semver docs

Coerces a string to semver if possible.

Aims to provide a very forgiving translation of a non-semver string to semver. It looks for the first digit in a string, and consumes all remaining characters which satisfy at least a partial semver, up to the maximum permitted length (256 characters).

Maximum length for any semver component considered for coercion is 16 characters; longer components will be ignored ( 10000000000000000.2.3.4 becomes 2.3.4).
