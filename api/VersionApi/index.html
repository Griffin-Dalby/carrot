VersionApi

Responsible for translating semver strings into Version objects, and back. It also handles wildcard 1.x & partial 1.2 strings.

Types​

Version​

</>
type Version = {
major: number,
minor: number,
patch: number
}

Primitive datatype that represents a deconstructed version, split up into their respective components.

ConvertibleVersion​

</>
type ConvertibleVersion = Version | string

Abstracted datatype allowing you to either pass a deconstructed Version, or a semver string that will then be deconstructed.

Functions​

FromString​

</>
VersionApi.FromString(version: string) → Version

Translates a semver string into a Version object. Places that are held by a wildcard (*, X, x), or cut off as a partial, will be replaced with zeros.

Example:

VersionApi.FromString("1.2.3") --> {major = 1, minor = 2, patch = 3}
VersionApi.FromString("1.2")   --> {major = 1, minor = 2, patch = 0} |  (Partial)
VersionApi.FromString("1.X.x") --> {major = 1, minor = 0, patch = 0} | (Wildcard)
VersionApi.FromString("1.*")   --> {major = 1, minor = 0, patch = 0} | (Wildcard)

ToString​

</>
VersionApi.ToString(version: Version) → string

Translates a Version object into a semver string.

Example:

local version_a = VersionApi.FromString("1.2.4")
local version_b = VersionApi.FromString("2.*")

Version.ToString(version_a) --> "1.2.4"
Version.ToString(version_b) --> "2.0.0"
